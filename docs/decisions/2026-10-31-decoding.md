# Decoding

v1 reads ProRes and DNxHR in MOV/MXF and H.264 in MP4 ([2026-10-31-first-formats-and-check-profile.md](2026-10-31-first-formats-and-check-profile.md)),
so FFmpeg through FrameReader (LGPL libraries, separate and replaceable) is in v1.

Question: what decodes H.264 in MP4.

Choices:

1. FFmpeg for everything (recommended): one path and one set of comparisons; ManagedCodecs later if a managed-only
   build is wanted.
2. Both: ManagedCodecs for H.264/AAC in MP4, FFmpeg for the rest.

Answer: 2. Two decoding paths, so a test checks that both give the same measures on the same MP4 (the H.264 sample
from tools/make-samples.sh), within the tolerances each figure states.
