# The name: Noga

media-qc and mediaqc were working names; the repository was to go public once it had a real one
(2026-11-03-mit-licence.md). Asked in rounds, each checked for NuGet package ids, GitHub and products already using
the name:

1. English and invented: Prooflight (recommended), Granska, Barline, FirstPass. The owner wanted softer
   Swedish-rooted words, like Klarna.
2. Invented soft forms: Synla (recommended), Siktra, Lugna, Kvitta, Klarvo. The owner meant a real Swedish word that
   hints at the job without describing it, as *klarna* (to clear up) does.
3. Real words: Skira (recommended), Mogna, Gilla, Sila. Do over.
4. Direction asked: Swedish TV and editing words (chosen), "done/approved" words, invented words, English.
5. TV words: Spola (recommended), Vinjett, Rutan, Rulla. Spola also means to flush; generic Swedish words instead.
6. Generic words: **Noga** (recommended), Ordna, Hinna.

Answer: **Noga** (Swedish: careful, thorough). Free as a NuGet id; a few small firms share the name (Noga CS, NogaTech,
an HR app), none in video.
