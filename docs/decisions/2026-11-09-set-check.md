# A book as one check: noga check FOLDER

Asked 2026-11-09, with the acx profile ([2026-11-09-acx-profile.md](2026-11-09-acx-profile.md)). An audiobook is
delivered as a set of files, one a chapter, which ACX judges together as well as one by one: every file mono or every
file stereo, the same format, levels that match. Today each file is a check of its own.

Question: is the set check a new command or a grouping in the report?

- **`noga check FOLDER`** (recommended): giving `noga check` a folder checks its files as one set: each file's report,
  plus one summary (the same format throughout, levels within a tolerance of each other), and one exit code. No new
  verb.
- A new command, `noga book FOLDER`, writing the per-file reports and the book's summary; check stays one file.
- A grouping in the UIs only: the web UI and the app group a folder's jobs under one summary row; the command line
  stays per file.

**Answer: `noga check FOLDER`.** Built after the single-file acx profile, as its own backlog item; what the summary
compares, and the tolerance, are decided then.
